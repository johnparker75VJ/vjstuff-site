## GitHub Pages
Create a GitHub repository (for example `vjstuff-site`), upload the contents of this folder, then open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

After publishing, the privacy URLs are:
- `/privacy/my-hyrox.html`
- `/privacy/my-marathon.html`
- `/privacy/how-many-sleeps.html`
- `/privacy/ourworship.html`

Before store submission, check each policy against the exact production build and update the Google Play Data Safety / Apple App Privacy declarations to match.
